01When to use DP

The question asks

A count ("number of ways"), a min/max ("fewest coins", "max money"), or yes/no ("can you partition").

Each step is a choice

Take or skip, which coin next, where to cut, match or skip a character.

Greedy breaks

Coins [1, 3, 4], amount 6: greedy takes 4+1+1, optimal is 3+3.

02Key ideas

State

What one cell means, in words. House Robber: dp[i] = most money from the first i houses. Write it as a comment before coding.

Transition

How a cell is built from earlier cells. Skip house i (dp[i-1]) or rob it (dp[i-2] + nums[i-1]); take the max.

Base case and answer

dp[0] = 0, dp[1] = nums[0]. Answer: dp[n].

Shrink the space

If a cell reads only a fixed window of earlier cells, keep just that window. House Robber needs two variables.

Recursionexponential→ Memoisationtop-down, cache by state→ Tabulationbottom-up loop→ Space optimisedkeep only rows you read

Figure: the four-step progression interviewers expect you to narrate. Memoisation is the safest start under pressure; tabulation removes recursion depth risk; the last step drops memory.

Go deeper: the original explanations and trace tables

Constraints hint: n ≤ 103 to 104 for O(n²), or amounts ≤ 104 for O(n × amount).

DP applies when a problem has overlapping subproblems (plain recursion would solve the same smaller question many times) and optimal substructure (the best answer is built from best answers to smaller questions).

State, transition, base case

Take House Robber: houses in a row, no two adjacent can be robbed, maximise loot.

  • State: dp[i] = most money from the first i houses. Write the definition in a comment before coding; most DP bugs come from a vague state.
  • Transition: for house i, skip it (dp[i-1]) or rob it (dp[i-2] + nums[i-1]). Take the max.
  • Base case: dp[0] = 0 (no houses), dp[1] = nums[0].
  • Answer: dp[n].

Space optimisation works whenever the transition reads a fixed window of previous states. House Robber reads only dp[i-1] and dp[i-2], so two variables suffice. Trace on [2, 7, 9, 3, 1]:

Unbounded knapsack

Items can be reused. For the fewest coins, dp[a] = min over coins c ≤ a of dp[a − c] + 1. With coins [1, 2, 5] and amount 11, dp[0..11] = 0, 1, 1, 2, 2, 1, 2, 2, 3, 3, 2, 3. For counting combinations, loop coins on the outside so each combination is counted once in a fixed coin order; loop amounts on the outside and you count permutations instead.

LIS in O(n log n): patience sorting

Keep tails[k] = the smallest possible last value of an increasing subsequence of length k + 1. tails is always sorted, so for each new value binary search the first tail ≥ it and overwrite it (or append). The length of tails is the LIS length; its contents are not necessarily a valid subsequence.

04Java templates

O(n)House Robber memo / table
O(coins × amount)knapsack counting, O(amount) space
O(m × n)two-string LCS, time and space

Memoised and tabulated House Robber, unbounded-knapsack counting, and longest common subsequence. The space-optimised robber is problem 5.1.

Show Java solution
import java.util.*;

class DpTemplates {
    // Step 1: memoised recursion. best(i) = max loot from houses i..n-1.
    static int robMemo(int[] nums) {
        Integer[] memo = new Integer[nums.length];
        return best(nums, 0, memo);
    }

    private static int best(int[] nums, int i, Integer[] memo) {
        if (i >= nums.length) {
            return 0;                                           // base case: no houses left
        }
        if (memo[i] != null) {
            return memo[i];
        }
        int skip = best(nums, i + 1, memo);
        int take = nums[i] + best(nums, i + 2, memo);
        return memo[i] = Math.max(skip, take);
    }

    // Step 2: tabulation. dp[i] = max loot from the first i houses.
    static int robTable(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n + 1];
        dp[1] = n > 0 ? nums[0] : 0;
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[n];
    }

    // Unbounded knapsack: number of ways to make amount (coin order does not matter).
    static int countWays(int[] coins, int amount) {
        int[] ways = new int[amount + 1];
        ways[0] = 1;
        for (int c : coins) {                                   // coins outer: combinations, not permutations
            for (int a = c; a <= amount; a++) {                 // ascending a: coin c reusable
                ways[a] += ways[a - c];
            }
        }
        return ways[amount];
    }

    // Subsequence DP on two strings: longest common subsequence.
    static int lcs(String x, String y) {
        int[][] dp = new int[x.length() + 1][y.length() + 1];
        for (int i = 1; i <= x.length(); i++) {
            for (int j = 1; j <= y.length(); j++) {
                dp[i][j] = x.charAt(i - 1) == y.charAt(j - 1)
                    ? dp[i - 1][j - 1] + 1
                    : Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[x.length()][y.length()];
    }
}

Integer[] memo usual pick

  • null means "not computed"
  • A real answer of 0 is not confused with "missing"

int[] memo

  • Needs Arrays.fill(memo, -1)
  • Breaks if −1 can be a valid answer
Partition DP shape

dp[j] = best answer for the prefix ending at j. Try every last piece s[i..j]; if valid, combine with dp[i-1]. O(n²) transitions, so validity must be O(1), usually a precomputed table. Word Break and Palindrome Partitioning II follow it.

05Worked problems

5.1 House Robber LeetCode 198: house-robber ↗

Level
Medium
Task
Houses in a line with money; no two adjacent robbed. Maximise loot.
Insight
best(i) = max(best(i-1), best(i-2) + nums[i]), needing only the last two values.
Cost
O(n) time, O(1) space.
Show Java solution
class Solution {
    public int rob(int[] nums) {
        int prev2 = 0;                 // best up to house i-2
        int prev1 = 0;                 // best up to house i-1
        for (int x : nums) {
            int cur = Math.max(prev1, prev2 + x);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
Go deeper: edge cases

One house; two houses (take the larger); all zeros.

5.2 House Robber II PhonePe Amazon Walmart Zeta Flipkart LeetCode 213: house-robber-ii ↗

Level
Medium
Task
Same rule, but houses form a circle: first and last are neighbours.
Insight
One of house 0 or n−1 is always skipped. Run the linear robber on [0, n−2] and [1, n−1]; take the max. Most-reported DP problem in the set.
Cost
O(n) time, O(1) space.
2325run 1: drop last
2325run 2: drop first
Show Java solution
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) {
            return nums[0];
        }
        // the first and last house are neighbours, so never take both
        return Math.max(robLine(nums, 0, n - 2), robLine(nums, 1, n - 1));
    }

    private int robLine(int[] nums, int from, int to) {
        int prev2 = 0;
        int prev1 = 0;
        for (int i = from; i <= to; i++) {
            int cur = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
Go deeper: edge cases and House Robber III

Edge cases. n = 1 must return nums[0] (both ranges would otherwise be empty); n = 2 returns the larger value; [1, 2, 3] → 3, not 4.

Interviewers then ask for House Robber III (tree) as the follow-up.

Follow-up: House Robber III (binary tree). Post-order DFS returning a pair {robThis, skipThis}: robThis = node.val + left.skip + right.skip, skipThis = max(left) + max(right). O(n) time, O(h) stack.

5.3 Coin Change Kotak LeetCode 322: coin-change ↗

Level
Medium
Task
Unlimited coins. Fewest coins summing to amount, or −1.
Insight
Unbounded knapsack: dp[a] = min(dp[a − c] + 1). Use amount + 1 as infinity so + 1 never overflows.
Cost
O(amount × coins) time, O(amount) space.

Coins [1, 2, 5], amount 11. Each cell is dp[a]:

011221223323
Show Java solution
import java.util.*;

class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];              // dp[a] = fewest coins to make a
        Arrays.fill(dp, amount + 1);                 // amount + 1 acts as infinity
        dp[0] = 0;
        for (int a = 1; a <= amount; a++) {
            for (int c : coins) {
                if (c <= a) {
                    dp[a] = Math.min(dp[a], dp[a - c] + 1);
                }
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
Go deeper: edge cases and Coin Change II

amount = 0 → 0; unreachable amount ([2], 3) → −1; using Integer.MAX_VALUE as infinity overflows on + 1. Follow-up: Coin Change II (number of combinations) uses the countWays template with coins in the outer loop.

5.4 Decode Ways Angel One LeetCode 91: decode-ways ↗

Level
Medium
Task
Letters map to "1".."26". Count the ways to decode a digit string.
Insight
Climbing stairs with conditions: last letter used one digit (not '0') or two digits (10..26). dp[i] = (one ok ? dp[i-1] : 0) + (two ok ? dp[i-2] : 0).
Cost
O(n) time, O(1) space.

"226" → 3 ways: 2-2-6, 22-6, 2-26.

1123
Show Java solution
class Solution {
    public int numDecodings(String s) {
        int prev2 = 1;                                    // ways to decode s[0..i-2) (empty prefix = 1)
        int prev1 = s.charAt(0) == '0' ? 0 : 1;           // ways to decode s[0..i-1)
        for (int i = 2; i <= s.length(); i++) {
            int cur = 0;
            if (s.charAt(i - 1) != '0') {
                cur += prev1;                             // last char as a single letter
            }
            int two = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
            if (two >= 10 && two <= 26) {
                cur += prev2;                             // last two chars as one letter
            }
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
Go deeper: trace and edge cases

Trace on "226": start (1, 1); i = 2: "2" ok → 1, "22" ok → +1 = 2; i = 3: "6" ok → 2, "26" ok → +1 = 3. Answer 3 (2-2-6, 22-6, 2-26).

Edge cases. Leading '0' → 0; "10" → 1; "100" → 0 (the second '0' cannot stand alone and "00" is not valid); "27" → 1. Follow-up: Decode Ways II with '*' wildcards multiplies counts per case and needs mod 109+7.

5.5 Palindrome Partitioning II Zeta LeetCode 132: palindrome-partitioning-ii ↗

Level
Hard
Task
Cut a string into palindromes with the fewest cuts.
Insight
Partition DP: cuts[j] = min cuts for s[0..j]. For each palindromic last piece s[i..j]: cuts[i−1] + 1, or 0 when i = 0. Fill the palindrome table in the same loop.
Cost
O(n²) time, O(n²) space for the table.
aa|b→ 1 cut
Show Java solution
class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];             // pal[i][j]: s[i..j] is a palindrome
        int[] cuts = new int[n];                         // cuts[j]: min cuts for s[0..j]
        for (int j = 0; j < n; j++) {
            cuts[j] = j;                                 // worst case: every char alone
            for (int i = 0; i <= j; i++) {
                if (s.charAt(i) == s.charAt(j) && (j - i < 2 || pal[i + 1][j - 1])) {
                    pal[i][j] = true;
                    cuts[j] = i == 0 ? 0 : Math.min(cuts[j], cuts[i - 1] + 1);
                }
            }
        }
        return cuts[n - 1];
    }
}
Go deeper: details, O(n) space and edge cases

s[i..j] is a palindrome if the end characters match and the inside is one (or the length is ≤ 2). An O(n) space variant expands around each centre and updates cuts as it goes.

Edge cases. Single character → 0; whole string already a palindrome → 0; all distinct characters → n − 1. Order of loops matters: pal[i+1][j-1] must be filled before pal[i][j], which holds because column j−1 is complete when you reach column j.

5.6 Longest Palindromic Subsequence Paytm OA LinkedIn LeetCode 516: longest-palindromic-subsequence ↗

Level
Medium
Task
Length of the longest subsequence (not necessarily contiguous) that reads the same both ways.
Insight
The 2D stepper above. Ends match → dp[i+1][j−1] + 2; else max(dp[i+1][j], dp[i][j−1]). Fill i right to left. Also LPS(s) = LCS(s, reverse(s)).
Cost
O(n²) time and space; O(n) with two rows, since row i reads only row i+1.
Show Java solution
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];                      // dp[i][j]: LPS length inside s[i..j]
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;     // both ends join the palindrome
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
Go deeper: edge cases and related follow-ups

Length 1 → 1; all same characters → n; "cbbd" → 2. Related follow-ups: minimum insertions to make a palindrome = n − LPS; longest palindromic substring is a different problem (expand around centre).

5.7 Longest Increasing Subsequence Visa Staff LeetCode 300: longest-increasing-subsequence ↗

Level
Medium
Task
Length of the longest strictly increasing subsequence.
Insight
Baseline: dp[i] = 1 + max dp[j] over j < i with nums[j] < nums[i], O(n²). Say it first. Visa then asked for O(n log n): the tails stepper above with a lower-bound search.
Cost
O(n²) baseline; O(n log n) time, O(n) space with tails.
Show Java solution
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];                           // dp[i]: longest increasing run ending at i
        int best = 0;
        for (int i = 0; i < n; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            best = Math.max(best, dp[i]);
        }
        return best;
    }
}
Show Java solution (O(n log n) follow-up)
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];              // tails[k]: smallest tail of an increasing run of length k+1
        int size = 0;
        for (int x : nums) {
            int lo = 0;
            int hi = size;
            while (lo < hi) {                            // first tail >= x (lower bound)
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < x) {
                    lo = mid + 1;
                } else {
                    hi = mid;
                }
            }
            tails[lo] = x;
            if (lo == size) {
                size++;
            }
        }
        return size;
    }
}
Go deeper: duplicates and reconstruction

Strictly increasing means duplicates do not extend: lower bound (first tail >= x) replaces an equal tail, so [7,7,7,7] → 1. For non-decreasing, use upper bound (first tail > x). To reconstruct the actual subsequence, store for each element the index that sits before it (the tail at position lo − 1) and walk back from the last tail.

06Mistakes and follow-ups interviewers ask

Common mistakes
  • Jumping to a table without saying what dp[i] means. The interviewer cannot follow, and you lose the chance to catch an off-by-one.
  • Off-by-one between "first i items" (size n + 1) and "ending at index i" (size n) states.
  • Using Integer.MAX_VALUE as infinity and adding 1.
  • House Robber II without the n = 1 guard.
  • Claiming the tails array is the LIS itself.
  • Deep recursion in Java memoisation for n around 105: the default thread stack overflows; convert to tabulation.

Interview questions

Memoisation or tabulation: which do you choose?

Memoisation is quicker to get right and only computes reachable states. Tabulation avoids recursion overhead and stack overflow, and makes space optimisation possible because you control the fill order. In an interview, start with whichever you can write correctly, then convert if asked.

How do you know a greedy will not work?

Find a small counter-example. For coin change, [1, 3, 4] with amount 6 breaks largest-coin-first. For house robber, [2, 1, 1, 2] breaks "take every other house".

Coin change: combinations versus permutations?

Coins in the outer loop and amounts inner counts combinations (1+2 equals 2+1). Amounts outer, coins inner counts ordered sequences, which is Combination Sum IV.

Can LIS be done with a TreeSet?

Yes for strictly increasing: for each x, remove ceiling(x) if present and add x; the set size is the answer. Same O(n log n), but the array version has lower constants and handles reconstruction more easily.

Russian Doll Envelopes is a common LIS follow-up. What is the trick?

Sort by width ascending and, for equal widths, height descending; then run LIS on heights. The descending tie-break stops two envelopes of the same width from nesting.

07Quick check

Decode Ways: what are the state and base case?

State: dp[i] = number of decodings of the first i characters. Transition: add dp[i−1] if s[i−1] ≠ '0', add dp[i−2] if s[i−2..i−1] is 10..26. Base: dp[0] = 1, dp[1] = s[0] == '0' ? 0 : 1.

Why does House Robber II split into two linear runs?

Excluding each end house in turn covers every valid plan.

What is tails after processing [3, 1, 4, 1, 5]?

[3] → [1] → [1, 4] → [1, 4] (1 replaces 1) → [1, 4, 5]. LIS length 3.

Longest palindromic subsequence of "bbbab"?

4 ("bbbb"), as the 2D stepper shows.

When can a 2D DP drop to one row?

Keep two arrays, or one array if you choose the inner loop direction so you never overwrite a value you still need.

08Cheat sheet

Cheat sheet
  • Count / min-max / yes-no + choices + greedy fails → DP.
  • Say state, transition, base case before coding.
  • Recursion → memo (Integer[]) → table → rolling variables.
  • Robber: max(dp[i-1], dp[i-2] + x); circle → two runs.
  • Coins: min(dp[a-c] + 1), infinity = amount + 1; coins outer = combinations.
  • Decode: add dp[i-1] if digit ≠ 0, dp[i-2] if 10..26.
  • Range DP: fill i right to left; ends match → inside + 2.
  • LIS: tails + lower bound, O(n log n); tails is not the subsequence.
